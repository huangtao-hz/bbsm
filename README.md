# 版本说明管理程序

单位的柜面系统定期投产，需要向分行发布版本投产的程序更新的内容。发布内容时需要进行格式化，以便发布的文档比较美观，同时，也可以对版本的参数进行标记。本程序分为两个模块，一个是版本格式化模块，另外一个是版本历史查询模块。

## 版本格式化

该程序处理待发布的版本说明文件，主要有以下功能：

1. 对单元格进行合并。
2. 计算单元格的高度。
3. 纠正版本说明中错误的交易名称。
4. 对于代投产的交易标记投产日期。
5. 输出文件后，生成源文件的备份。

## 版本说明功能

该程序处理已发布的版本说明文件，主要有以下功能：

1. 批量导入已发布的版本说明文件；
2. 支持按交易码查询版本说明历史；
3. 支持按任意关键词查询版本说明。

程序在导入文件时，分别从以下目录导入：
- MacBook: Cloud/资料库/版本说明
- Windows: OneDrive/资料库/版本说明
